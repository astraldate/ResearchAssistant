# 快捷命令与 PDF AI 降级修复方案

## 目标

修复移动端快捷命令无法直接执行、桌面划词翻译受损坏 ToUnicode CMap 阻断、移动术语解释内容层级退化的问题，并确保桌面与移动端调用同一套模型解释服务。

## 功能分解

1. 为有明确目标的命令生成受控默认问题；`/innovation` 等需要业务参数的命令继续要求用户输入。
2. PDF 划词翻译在已取得选中文字时，不因页面 Context 提取失败而终止。
3. 术语解释固定返回模型生成的通俗总结；百科结果作为资料增强，页面上下文单独展示且不代替总结。
4. 对失败降级和默认命令语义增加回归测试。
5. 更新文档和版本，重新构建桌面端与 Android。

## 实施步骤

1. 走查移动发送逻辑、PDF 共享服务与结果面板映射。
2. 修改共享服务及移动发送逻辑。
3. 增加 Rust/TypeScript 回归验证。
4. 更新 README 与 Design Specification。
5. 构建、安装并核验新版本。

## 验收标准

- `/brief @「论文」` 不需要额外输入即可发送；普通 `/ask` 无问题时给出清晰校验。
- ToUnicode CMap 解析失败时，已选文字仍能进入翻译模型。
- 术语解释面板首先展示模型通俗解释，百科与页面上下文各自标记来源。
- Web、移动 TypeScript、Rust 测试、Windows NSIS 和 Android release 全部通过。
