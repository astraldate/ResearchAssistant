# 移动端导航与资料库整合方案

## 目标定义

将移动端底部导航从六个入口精简为四个高频主域；把采集合并到聊天，把复习合并到卡片库；同步展示桌面笔记库与知识卡片，并提供带确认的删除操作；修复聊天输入区与 `/`、`@` 菜单的层级关系。

## 功能分解

1. 聊天页顶部提供“聊天 / 采集”切换，复用现有采集表单与桌面收件箱接口。
2. 卡片库顶部提供“卡片 / 复习”切换，复用现有离线复习队列。
3. 底部 Tab 隐藏独立的采集与复习路由，保留旧路由文件以兼容已有深链。
4. 资料库展示桌面同步的知识卡片与笔记，并在删除前显示明确确认；删除成功后同步清理手机缓存。
5. 聊天页面只让消息区滚动，输入 Dock 固定在底部；候选菜单显示在 Dock 上方并可独立滚动。

## 实施步骤

1. 核对共享协议、移动 API、SQLite 缓存以及 Rust companion service 的笔记和卡片能力。
2. 抽取可复用的采集与复习视图，嵌入聊天和卡片库。
3. 增加资料删除端点、移动 API 和缓存删除逻辑，并补充确认交互。
4. 精简 Tab 配置，保留旧路由兼容跳转。
5. 执行 Prettier、移动与 Web TypeScript、Rust 格式/检查/测试和 Android release 构建。

## 验收标准

- 底部只显示卡片库、论文、聊天、设置四个入口。
- 聊天页顶部可切换到采集，返回聊天后输入和会话状态不被意外清空。
- 卡片库顶部可切换到复习，评分仍可离线排队并同步回桌面。
- 笔记和知识卡片能从桌面同步到手机，删除前有确认，删除后桌面与手机列表一致。
- 聊天输入框稳定贴近页面底部，`/` 与 `@` 列表不会被工具栏、输入框或系统键盘遮挡。
