# 移动端编辑与创新删除方案

## 目标定义

- `/` 与 `@` 快捷按钮在当前光标或选区处插入，候选选择后可继续编辑并正常发送。
- 手机端能够创建和编辑知识卡片、论文笔记，桌面端继续作为权威存储。
- 手机端能够删除生成的创新结果，并同步清理桌面 Idea Map。
- 引用卡片不展示含大量 Unicode 替换字符的低质量证据片段。

## 功能分解

1. 输入框记录 selection，触发符与候选 Token 按 selection 范围插入或替换。
2. 移动协议新增卡片、笔记创建和更新请求；服务端只接受资源 ID，不接受任意桌面路径。
3. 知识页增加创建按钮、编辑按钮和 Markdown 编辑表单；桌面成功后执行 bootstrap 同步。
4. 创新页与聊天创新卡增加删除按钮；服务端事务式删除 Idea、支持边并清除会话结构化字段。
5. 引用片段进入移动协议前执行字符质量清洗，低质量片段返回空字符串。

## 实施步骤

1. 修复聊天输入 selection 状态与发送正文解析。
2. 扩展共享协议、Rust 路由和受控资源定位函数。
3. 接入移动 API、知识页创建编辑抽屉和本地同步刷新。
4. 实现创新删除服务与移动确认交互。
5. 增加 Rust 与 TypeScript 检查，更新 README 和设计规范。
6. 升级版本并构建 Windows NSIS 与 Android release。

## 验收标准

- 光标位于正文中间时点击 `/` 或 `@`，Token 在光标处出现，原有前后文本不丢失。
- 选择快捷项、继续输入正文后能够发送，服务端只收到一次结构化命令或论文范围。
- 手机新建或编辑卡片、笔记后，桌面文件与手机列表同步一致；离线时不执行假保存。
- 删除创新结果后，手机创新列表和桌面 Idea Map 均不再显示该 Idea。
- 引用卡片不显示 `�` 密集片段。
